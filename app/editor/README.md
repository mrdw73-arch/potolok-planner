# Professional editor

Route: `/editor`

This route is the next-generation geometry editor prototype. It demonstrates the geometry workflow before replacing the legacy home screen:

- snap 10/50/100 mm;
- 90° orthogonal mode;
- live area/perimeter;
- corner angle and diagonal;
- pointer capture while dragging;
- ceiling variants.

The existing `/` route remains intact while the new editor is integrated incrementally.
