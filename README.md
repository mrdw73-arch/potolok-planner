# Potolok Planner

Планировщик и расчёт натяжных потолков.

## Что уже есть

- редактирование формы помещения;
- расчёт площади и периметра;
- добавление светильников, люстр и карнизов;
- каталог материалов и расчёт стоимости;
- варианты потолка;
- сохранение проектов в браузере;
- импорт и экспорт резервной копии;
- подготовка к облачной синхронизации через Supabase.

## Стек

- Next.js 15
- React 19
- TypeScript
- Supabase

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`.

## Переменные окружения

Для функций Supabase используйте публичные переменные окружения приложения (`NEXT_PUBLIC_*`). Секретный service-role key нельзя помещать в клиентский код.

## Работа через Codex

Репозиторий подключён к GitHub, а инструкции для Codex находятся в `AGENTS.md`. Для каждой крупной функции рекомендуется работать отдельной веткой и открывать Pull Request в `main`.
