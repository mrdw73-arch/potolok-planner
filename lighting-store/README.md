# LumiHub

MVP единого каталога освещения внутри репозитория `potolok-planner`. В Vercel используется Root Directory: `lighting-store`.

## Цель
- единый каталог товаров разных брендов;
- импорт через API/XML/CSV/разрешённый парсинг;
- нормализация названий, характеристик, цен и изображений;
- обновление остатков и цен;
- корзина и оформление заказа.

Следующий этап — подключение первого реального поставщика и серверного import engine.
